# Agent Guide

Repository layout:

- `src/`: reusable analysis code added later.
- `tests/`: unit tests added later.
- `notebooks/`: Jupyter analysis notebooks.
- `data/raw/`: original local recordings.
- `data/processed/`: derived local data.
- `data/external/`: external reference data.
- `reports/figures/`: generated figures.
- `reports/pdfs/`: generated PDFs.
- `temp/`: scratch files.
- Root files: Conda env, package metadata, README, PyTorch CUDA notes.

Data, images, PDFs, reports, and temp files stay out of git.
